# Personal Developer Portfolio

A modern and responsive personal portfolio website built to showcase my skills, technologies, projects, and journey as a junior software developer.

The website provides an introduction about me, highlights my technical interests and development skills, and includes a section where visitors can explore my projects and get in touch with me.

### Technologies Used

* HTML5
* CSS3
* JavaScript

### Features

* Responsive modern design
* Hero/landing section
* About/Introduction section
* Skills and technologies section
* Projects showcase
* Contact form
* Project comments section
* Social media links
* Smooth navigation
* Responsive layout for mobile and desktop

### Purpose

I created this project as part of my journey to improve my web development skills and build a professional online presence. I will continue updating the website as I learn new technologies and complete more projects.
